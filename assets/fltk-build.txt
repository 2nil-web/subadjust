Fltk is widely available under linux, MSys2 even for Visual Studio/vcpkg
In any case a fresh fltk build is necessary do what follow :

Clone fltk git repo: 
 > git clone https://github.com/fltk/fltk.git
 > cd fltk
 > git tag #  to see which tag crrepond to the latest fltk version (release-1.4.5 as of 2023/05)

if needed switch to latest 1.4 version :
 > git checkout release-1.4.X
or stay on master : 
 > git checkout -

Setting fltk for Linux (Ubuntu-24.04) :
---------------------------------------
* Prerequisites for Linux build (To confirm/Consolidate) :
  - gcc/g++
  - make
  - cmake
  - ImageMagick (not sure but necessary for subadjust)
  - Inkscape (same remark)
  - pandoc (same)
  - librsvg2-bin (for subadjust delivery)
  - apt install texworks texlive-latex-recommended -y (same)
  - waylandpp-dev
  - aptinstall libwayland-bin libwayland-client0 libwayland-cursor0 libwayland-dev libwayland-egl1 libwayland-server0 wayland-protocols
  - librsvg2-dev
  - libx11-dev
  - libgl1-mesa-dev
  - libjpeg, libjpeg-dev
  - apt install libglu*
  - pkg-config
  - libxinerama-dev libXfixes-dev
  - libdbus-cpp-dev
  - libxcursor-dev libxkbcommon-dev
  - libdecor-0-dev
* Prepare :
 -  To get the fltk "semantic conformant version" corresponding to the current tag, if possible, then do the following :
 > git describe --exact-match --tags 2>/dev/null && VERS=$(git describe --exact-match --tags) || VERS=""
 - Or more shortly (as of may 2026) :
 > export VERS=1.4.5 # (or export VERS=latest)
 - If not already done, install X11-dev and Mesa3D : 
 > apt install libx11-dev; apt install libgl1-mesa-dev
* Configure :
 > cmake -DCMAKE_INSTALL_PREFIX:PATH=/opt/fltk/${VERS} . -B build
* Build :
 > cmake --build build
* And finally, install fltk :
 > cmake --install build

Setting fltk for Windows 11 and msvc 2026 (using dev prompt for VS 18) :
------------------------------------------------------------------------
* Prerequisites for Windows, see the prerequisite to subadjust in README.md
* Prepare :
 > set VERS=1.4.5
:: or > set VERS=latest
* Configure :
 - With the developper command prompt for VisualStudio (VS 18, as of 2026/05) :
 > cmake -S . -B build%VERS% -G "Visual Studio 18 2026" -A x64 -DBUILD_SHARED_LIBS=OFF -DCMAKE_INSTALL_PREFIX:PATH=C:\fltk\%VERS% -DFLTK_BUILD_EXAMPLES=OFF
* Build :
 > cmake --build build%VERS% --config Debug --target INSTALL
 > cmake --build build%VERS% --config Release --target INSTALL
* Install :
 > cmake --install build%VERS%

Setting for Windows can also be done done with MSys2 (Or Cygwin although I'm not using it anymore)
